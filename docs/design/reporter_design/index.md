# Reporter Design

This page is about the Reporter module. It will discuss the inputs and outputs of Reporter.

## Reporter Input

The Reporter module receives [Pickle](https://docs.python.org/3/library/pickle.html) files generated by the Analyser module. These files contain diagram information generated from analysing network fields. These files include both static graphs and animated ones.

## Reporter Output

The Reporter modules displays the input graphs using the pickle Python library along with [tkinter](https://docs.python.org/3/library/tkinter.html) and [seaborn](https://seaborn.pydata.org/) one by one.
