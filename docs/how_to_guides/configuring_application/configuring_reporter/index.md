# Configure reporter

The reporter tab is responsible to display generated pickle graphs by Analyser.

## Directory Selection

To view these reports, after Analyser has processed the input and generated the graphs, click on browse and locate the generated `outputs` folder. Then locate `graphs` and then your desired RSU, OBU or RSU-OBU pair directory. Then locate `pickles` and select choose.

<div>
    <img src="../../../assets/images/reporter_browse.png" alt="UI Reporter tab with the graphs folder selected and a list of graphs displayed" class="configure_img"/>
</div>

## File Selection

Out of the list of graphs shown on the tab, select as many as you want.

<div>
    <img src="../../../assets/images/reporter_display.png" alt="UI Reporter tab with the graphs selected and the display button clicked" class="configure_img"/>
</div>

## Display

Clicking on display should bring up their graphs. Note that the 3D graphs are interactive.
